# Modular Landscape: smk37/

This folder is the SMK-37 Elite tree: Modular Compagnon's, with the bowed guitar (`ARCHET=1`: `firmware/src/archet.c`, `ar_land.c`, `ar_book.c`, `ar_tape.c`, `tools/archet/`). Start from the [README](../README.md) at the top of the repository; `../build.sh` builds both
packages. `README-COMPAGNON.md` and `README-FELUCCA.md` describe the firmwares this tree comes from.

The guitar recordings in `tools/archet/` are not under the GPL: see [SOUNDS.md](../SOUNDS.md).
