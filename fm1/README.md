# Modular Landscape: fm1/

This folder is the FM-1 tree: Modular One's, with the bowed guitar (`BOARD=land`: `firmware/src/ls_ui.c`, `ls_draw.c`, `tools/archet/`). Start from the [README](../README.md) at the top of the repository; `../build.sh` builds both
packages. `README-COMPAGNON.md` and `README-FELUCCA.md` describe the firmwares this tree comes from.

The guitar recordings in `tools/archet/` are not under the GPL: see [SOUNDS.md](../SOUNDS.md).
